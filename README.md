ChronosEmulator 1.0
ChronosEmulator is a browser-based x86 PC emulator styled like an authentic 1990s desktop computer, nicknamed as "v86 Styled Edition". You can try it live at edgeone.dev. It lets you run classic operating systems from PC-DOS 1.00 all the way up to Windows 95 and early Linux distributions like Debian 1.3 right inside your web browser.
Unlike plain web emulators that only show a flat black screen with modern fonts, ChronosEmulator gives you a full beige PC chassis and a retro CRT monitor. You can turn the CRT scanline effect on or off, and text mode uses genuine MS-DOS VGA fonts. When you insert a floppy disk or CD-ROM image into the A:, B:, or CD/DVD: drives, you actually see the disk sticking out of the slot alongside glowing green activity lights and working eject buttons. The front panel also includes working Power, Reset, Lock Mouse, and Fullscreen buttons, along with Sound Blaster 16 audio and Network Relay support.
To get started, open the website and upload your three firmware files (1.wasm, 2.bios, and 3.vga). You only need to do this once because ChronosEmulator saves them into your browser's IndexedDB cache for future visits. After that, you can either upload an existing hard drive image or create a blank virtual hard drive from 64MB up to 2GB right from the top menu. Pick your RAM amount from 4MB to 2GB, press Run, and insert your boot floppies or discs. If you make changes to your hard drive, click Save HDD anytime to download a backup copy.
ChronosEmulator is also built with Chromebook users in mind. Since Chromebooks do not have a standard Delete key, pressing Ctrl + Alt + Backspace automatically sends Ctrl + Alt + Del to the virtual machine so you never get stuck on login screens or frozen DOS prompts.
This is version 1.0 of ChronosEmulator, and more ideas are on the way for version 2.0. Feel free to explore the code, fork the project, and share any ideas you have for future updates.
